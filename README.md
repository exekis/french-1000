# French 1000

A static French vocabulary site for absolute beginners. It will present a ranked list of 1,000 words with English and Persian meanings, one simple French example per word, and a one-click pronunciation control.

The implementation contract is in [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md). This repository is deliberately documentation-only until that plan is accepted and implementation begins.

## Status

Scaffolded on 2026-08-29. The original 1,000-word workbook has not been provided to this repository yet, so no vocabulary or audio has been generated.
